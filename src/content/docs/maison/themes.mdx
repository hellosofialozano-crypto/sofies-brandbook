# Themes

Maison supports adaptive experiences through semantic tokens.

---

## Light Theme

Designed for:

- Editorial reading
- Documentation
- Long sessions

---

## Dark Theme

Designed for:

- Reduced visual intensity
- Development environments
- Immersive experiences

---

## Rule

Components should never choose colors directly.

They consume semantic tokens.
