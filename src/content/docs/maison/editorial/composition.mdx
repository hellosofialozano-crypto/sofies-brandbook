# Composition

Composition is how Maison creates meaning.

---

## Editorial Rhythm

A page follows:

1. Introduction
2. Context
3. Detail
4. Reflection

---

## Whitespace

Whitespace is not unused space.

It is a pause.

---

## Alignment

Elements should feel intentionally placed.

Avoid:

- unnecessary decoration
- excessive containers
- visual noise

---

## Principle

Every screen should feel edited.
