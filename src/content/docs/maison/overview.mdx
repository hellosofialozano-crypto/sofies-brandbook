# Maison

## The SOFI'ES Design System

Maison is the system behind the SOFI'ES Collection.

It translates the philosophy of:

> Software, edited.

into a consistent digital language.

---

## Purpose

Maison creates alignment between:

- Product design
- Engineering implementation
- Documentation
- User experience

---

## Layers

Maison is organized into four layers:

### Foundations

The raw materials.

- Color
- Typography
- Spacing
- Motion
- Tokens

---

### Themes

Adaptive experiences.

- Light
- Dark

---

### Components

Reusable interface patterns.

- Layout
- Navigation
- Content
- Interaction

---

### Guidelines

Rules that protect quality.

- Accessibility
- Usage
- Evolution
