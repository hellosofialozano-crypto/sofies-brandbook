# Typography

Typography is the primary interface between software and humans.

---

## Principles

Maison typography follows three rules:

## 01. Clarity

Text should always communicate before decorating.

## 02. Hierarchy

Every level should have a clear purpose.

## 03. Restraint

Use scale intentionally.
